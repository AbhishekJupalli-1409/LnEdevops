# Employee platform

Read [reference.md](reference.md) for the request path, pipeline order, and failures already hit in this environment. Follow `docs/RUNBOOK.md` for a from-scratch deploy.

## Layout

| Path | Role |
|---|---|
| `terraform/bootstrap` | Once, local state. Creates the remote-state storage account only. |
| `terraform/envs/centralindia` | Root stack. |
| `terraform/modules/*` | policy, networking, acr, aks, aci, postgresql, keyvault, agent-vm, azuredevops. |
| `pipelines/` | Azure Pipelines YAML in this repo. App pipelines clone upstream GitHub repos. |
| `gitops/clusters/aks-centralindia/apps/` | Human-written Kubernetes YAML. Flux applies it. |
| `gitops/.../flux-system/` | Generated by `flux bootstrap`. Do not hand-edit. |
| `helm/nginx-ingress-values.yaml` | ingress-nginx chart values. |

## Fixed names

| Thing | Name |
|---|---|
| Resource group | `rg-empapp-centralindia` |
| AKS | `aks-empapp-cin` (private API) |
| State RG / container | `rg-empapp-tfstate-cin` / `tfstate` |
| ARM service connection | `empapp-arm` |
| Variable group | `empapp-shared-vars` |
| Agent pool / VM | `empapp-private-pool` / `vm-empapp-agent` |
| Apply environment | `empapp-infra-production` |
| Images | `employee-app-frontend`, `employee-app-backend`, `todo-list-app` |
| ACI | `aci-empapp-backend` on port 8000 |

ACR login server is `acrempapp<random>.azurecr.io`. Read it from the portal or `terraform output`. Do not trust stale defaults such as `acrempapp6ickq` in `pipelines/flux-bootstrap-azure-pipelines.yml`.

## Rules that are easy to get wrong

- Leave `manage_azure_devops = false`. Create the Azure DevOps project, pool, service connection, variable group, and pipelines in the UI.
- Never set `azdo_personal_access_token = ""` in `terraform.tfvars`. An empty value overrides `TF_VAR_*` and the pipeline secret. The secret name is `azdoPersonalAccessToken`.
- The agent pool must exist before apply. The run-command registers `vm-empapp-agent`. A second VM fails if that name is already in the pool. Delete the offline agent first.
- `enable_policy_assignments` stays `false` unless those subscription assignments are imported. Creating them again fails with "already exists".
- ACI create returns **400 InaccessibleImage** until `employee-app-backend:latest` is in this ACR. Build images, then apply again.
- Image pipelines push with `containerRegistry: $(acrServiceConnection)`. That variable is the **service connection name**, not the URL. The connection's registry must be the live login server. `lookup ... no such host` means the connection points at a deleted or mistyped ACR.
- Ingress and Flux pipelines use `pool: empapp-private-pool`. `az aks get-credentials` writes `~/.kube/config` on that VM; Helm and Flux then use it. A Microsoft-hosted agent can download the kubeconfig and still cannot reach the private API.
- Run ingress-nginx **before** Flux. Helm installs the controller and the public IP. Flux applies `/emp`, `/to-do`, and `/api`.
- Set `frontend_origin = "http://<ingress-ip>"` (no trailing slash) and apply again. `aci-backend-deploy` only restarts the container; it does not change `WHITELIST_URLS`.
- Browser calls `API_BASE_URL=/api` plus `/api/v1/employees/...`, so the public path is `/api/api/v1/employees/...`. Ingress strips the first `/api`. The React pod does not proxy to ACI.
- Todo uses SQLite inside its container. Only the Node API on ACI uses PostgreSQL. Key Vault stores a copy of the DB password; the request path does not read Key Vault.
- Do not install Docker assumptions onto the agent VM. Image builds belong on `ubuntu-latest`. The VM image is `azureagent` plus kubectl, Helm, and Flux. It has no Docker daemon unless someone added it.
